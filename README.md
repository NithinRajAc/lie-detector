# 🕵️‍♂️ Lie Detector App

A playful and interactive Lie Detector React Native application built with **Expo**, **Reanimated**, and **TypeScript**. 

This app simulates a premium fingerprint scanning lie detector with custom UI animations, haptic feedback, and a hidden prank mechanic that allows you to secretly control the outcome!

## ✨ Features

- **Interactive Fingerprint Scanner**: Press and hold to initiate the scan.
- **Dynamic Animations**: Buttery-smooth 60fps scanning laser and pulsating UI using `react-native-reanimated`.
- **Haptic Feedback**: Simulates the feeling of a real machine with device vibrations synced to the scanning animation.
- **Secret Prank Mechanic**:
  - 🟢 Tap the hidden **top-left corner** before scanning to force a **TRUTH** result.
  - 🔴 Tap the hidden **top-right corner** before scanning to force a **LIE** result.
  - 🎲 Don't tap anything? The result is randomly selected!
- **Premium Aesthetics**: Beautiful dark-mode gradient design with neon glow effects.

## 🚀 Tech Stack

- **Framework**: React Native & Expo
- **Language**: TypeScript
- **Animations**: `react-native-reanimated`
- **Device Features**: `expo-haptics`
- **Styling**: `expo-linear-gradient`

## 🛠️ How to Run Locally

1. Clone the repository:
   ```bash
   git clone https://github.com/NithinRajAc/lie-detector.git
   ```
2. Navigate to the project directory:
   ```bash
   cd lie-detector
   ```
3. Install dependencies:
   ```bash
   npm install
   ```
4. Start the Expo server:
   ```bash
   npx expo start
   ```
5. Scan the QR code using the **Expo Go** app on your physical device, or press `i` to open it in an iOS Simulator.
